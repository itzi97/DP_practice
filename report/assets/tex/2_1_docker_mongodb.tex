\section{Phase 1 \textemdash\ Environment Setup}

\subsection{MongoDB Preparation}

\par
The first thing I needed to do was find a MongoDB Docker image compatible with Spark 3.5.x.
This wasn't hard --- there's an official image on Docker Hub which I used as the base:
\href{https://hub.docker.com/_/mongo}{https://hub.docker.com/\_/mongo}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{2_1_dockerhub_mongo.png}
    \caption{Official MongoDB image on Docker Hub}
\end{figure}

\par
I went with version 6.0 since it's supported by the MongoDB Spark Connector 10.x, which
is what Spark 3.5.x requires. I added it to \texttt{docker-compose.yml} as the first service:

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{2_1_compose_mongodb.png}
    \caption{docker-compose.yml with the MongoDB service}
\end{figure}

\par
I started the container and checked it was up with \texttt{docker ps}:

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{2_1_mongodb_up.png}
    \caption{MongoDB container running}
\end{figure}

\par
Then I opened the MongoDB shell to set up the \texttt{practice} database needed for the project:

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{2_1_mongosh_enter.png}
    \caption{Accessing the MongoDB shell via \texttt{docker exec -it mongodb mongosh}}
\end{figure}

\par
To create the database I inserted a temporary document into a dummy collection and then deleted it ---
MongoDB only persists a database once it has data. On the first try I made a syntax error
(\texttt{\{( )\}} instead of \texttt{\{\}}), caught it immediately and ran the correct command.
The \texttt{show dbs} output confirms \texttt{practice} was created successfully:

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{2_1_mongosh_practice_db.png}
    \caption{Creating the \texttt{practice} database and verifying with \texttt{show dbs}}
\end{figure}
