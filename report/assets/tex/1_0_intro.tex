This document contains the explanations alongside necessary screenshots for the development of a Big Data project for air traffic analysis done for a Data Processing class.

The project is divided into three phases:
\begin{enumerate}
	\item Preparation of the environment with Docker containers
	\item Data ingestion into the data lake
	\item Analysis of data ingested in the data lake
\end{enumerate}

The data used is based on the OpenFlights portal and consists of four datasets:

\begin{itemize}
	\item Countries
	\item Airlines
	\item Airports
	\item Routes
\end{itemize}
