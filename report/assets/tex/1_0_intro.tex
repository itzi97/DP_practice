\section{Introduction}

This report documents the development of a Proof of Concept (PoC) for air traffic analysis in a Big Data context, carried out for the Data Processing mandatory practice.

The project is divided into three phases:
\begin{enumerate}
    \item Preparation of the environment with Docker containers
    \item Data ingestion into the data lake
    \item Analysis of data ingested in the data lake
\end{enumerate}

The data used is based on the OpenFlights portal and consists of four datasets: Countries, Airlines, Airports, and Routes.
